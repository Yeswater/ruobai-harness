# ruobai-harness 完整产品迭代 Roadmap + 详细设计

## 迭代总原则

1. **架构中立**：所有能力以独立 `@ruobai/*` 插件包交付，通过 `cordis.yml` 声明式装配，不侵入核心内核，支持一键启用 / 卸载
2. **事件兼容**：所有操作均沉淀为标准事件，天然支持会话回放、审计与多视图投影
3. **边界正交**：沙箱、审批、编排、工具能力保持解耦，通过标准化接口交互，不破坏原有分层设计

### 二、新增能力迭代（基础补全）

#### 1. 本地密钥安全管理（工业可靠性・基础安全）

**核心方案**：解决 API 密钥明文存储的安全隐患，提供系统级加密存储能力
**详细设计**：

- 插件名：`@ruobai/secret-manager`
- 实现逻辑：接入系统原生密钥链，密钥加密存储不落地明文；运行时按需解密注入，沙箱内仅通过代理接口调用；配置面板支持密钥增删改，不暴露明文值
- 架构兼容：扩展配置加载逻辑，禁用插件则回退明文模式，无侵入核心

#### 2. 代码变更 Diff 预览（体验效率・编码基础）

**核心方案**：可视化展示 Agent 对代码的修改内容，降低人工核对成本
**详细设计**：

- 插件扩展：`@ruobai/file-panel`
- 实现逻辑：文件修改前自动生成快照，支持「原文件 / 修改后 / 统一 Diff」三种视图切换；支持逐行确认、单处拒绝、批量写入；变更全量沉淀为事件，兼容会话回放
- 架构兼容：基于现有文件面板插槽扩展，不修改核心会话逻辑

#### 3. 单步执行自校验（智能体闭环・基础纠错）

**核心方案**：工具调用后自动校验执行状态，避免错误步骤向下传递
**详细设计**：

- 插件名：`@ruobai/step-validator`
- 实现逻辑：挂载工具调用后置钩子，自动校验命令 exit code、代码语法、文件存在性；校验失败阻断后续步骤，触发重试提示；结果作为独立事件写入日志
- 架构兼容：基于 Cordis 事件钩子实现，可独立插拔，不侵入编排内核

### 二、新增能力迭代（核心闭环补全）

#### 1. 反思纠错双循环（智能体核心能力）

**核心方案**：将线性执行升级为「执行 - 校验 - 反思 - 修正」双循环，提升复杂任务成功率
**详细设计**：

- 插件名：`@ruobai/reflection-loop`
- 实现逻辑：双循环架构（外层任务计划、内层单步执行）；校验覆盖代码语法、命令状态、结果匹配度；校验不通过自动生成修正方案，可配置重试上限，超限升级人工审批；全流程沉淀事件可追溯
- 架构兼容：以编排中间件形式注入，不修改原有编排内核，可按需开关

#### 2. 模糊意图主动澄清（智能体核心能力）

**核心方案**：指令信息不全时主动追问补全，降低任务偏离率
**详细设计**：

- 插件名：`@ruobai/intent-clarifier`
- 实现逻辑：消息进入执行链路前，通过规则 + 轻量模型识别信息完备度；以结构化选项方式追问，支持多轮补全；确认后的约束自动注入任务上下文
- 架构兼容：消息前置处理中间件，独立插拔，不影响原有执行链路

#### 3. 仓库级代码语义索引（编码深度能力）

**核心方案**：实现全仓库符号级理解，支撑跨文件重构、依赖分析等复杂任务
**详细设计**：

- 插件名：`@ruobai/code-index`
- 实现逻辑：基于 TreeSitter 本地解析代码，提取函数、类、调用链、导入导出关系；文件变更增量更新索引；Agent 执行时自动注入关联符号上下文，替代盲盒式读文件
- 架构兼容：独立服务插件，仅提供只读检索接口；沙箱内不直接访问索引，保持安全边界

#### 4. 调试排障闭环（编码深度能力）

**核心方案**：实现报错 - 定位 - 修复 - 验证全链路自动排障
**详细设计**：

- 插件名：`@ruobai/debug-loop`
- 实现逻辑：自动捕获运行报错与堆栈；结合代码索引定位根因；生成修复方案并自动应用，重跑验证效果；支持多轮迭代，失败输出排障报告
- 架构兼容：基于反思循环扩展，复用校验重试机制，独立插件封装

#### 5. 任务断点续跑（工业可靠性能力）

**核心方案**：解决服务重启、崩溃导致长任务中断的问题，支持断点恢复
**详细设计**：

- 插件扩展：`@ruobai/task-orchestrator`
- 实现逻辑：每完成一个子任务自动持久化状态与上下文快照；服务重启后自动扫描未完成任务，从最近检查点恢复；恢复前校验环境一致性，变更则提示人工确认
- 架构兼容：扩展原有编排插件，不侵入核心事件日志体系

#### 6. 成本管控与限流熔断（工业可靠性能力）

**核心方案**：避免 API 超额费用与接口故障导致任务崩溃
**详细设计**：

- 插件名：`@ruobai/cost-control`
- 实现逻辑：支持单会话 / 单日 / 单任务 Token 预算上限，超限自动暂停；模型接口 QPS 限流，连续失败自动熔断降级；实时统计成本，支持阈值告警
- 架构兼容：挂载模型调用前置钩子，不修改模型提供方核心逻辑

#### 7. MCP 协议完整适配（生态标准化能力）

**核心方案**：兼容 Model Context Protocol 生态，复用海量第三方工具与数据源
**详细设计**：

- 插件名：`@ruobai/mcp-bridge`
- 实现逻辑：协议转换层对接 MCP 标准工具 / 资源 / 提示；支持本地 Stdio、远程 SSE 两种接入方式，自动发现注册工具；所有 MCP 调用统一走沙箱与审批流程
- 架构兼容：独立协议桥接插件，不修改内部工具标准，可独立启用

#### 8. 标准化插件 SDK（生态标准化能力）

**核心方案**：降低第三方插件开发门槛，统一开发规范
**详细设计**：

- 交付物：`@ruobai/sdk` 开发包 + 官方模板
- 核心内容：封装插件生命周期、服务注册、事件订阅、UI 插槽等基础能力；提供工具、面板、编排三类插件模板；内置类型定义与最佳实践
- 架构兼容：基于 Cordis 原生能力封装，不引入额外运行时依赖

### 二、新增能力迭代（差异化壁垒）

#### 1. 多智能体协作框架（智能体核心能力）

**核心方案**：支撑角色分工式复杂研发任务，实现多 Agent 并行协作
**详细设计**：

- 插件名：`@ruobai/multi-agent`
- 实现逻辑：内置开发者、测试、评审等基础角色，支持自定义；主 Agent 拆分分发任务，子 Agent 并行 / 串行执行，结果汇总；基于事件总线共享信息，各 Agent 上下文独立；按角色分级沙箱权限
- 架构兼容：每个子 Agent 为独立插件实例，复用单 Agent 全部能力，不修改核心架构

#### 2. 研发流程全链路集成（编码深度能力）

**核心方案**：深度融入 Git/CI/ 需求管理工作流，覆盖研发全流程
**详细设计**：

- 插件集：`@ruobai/devops-integration`（含 Git、CI、Issue 三个子插件）
- 实现逻辑：Git 支持自动建分支、规范提交、生成 PR、响应评审；CI 监听流水线结果，失败自动排障；自动解析 Issue 生成开发计划，完成后关联关闭；凭证统一由密钥管理器管理
- 架构兼容：以工具插件形式接入，复用审批与沙箱机制，外部网络统一管控

#### 3. 多技术栈通用适配层（编码深度能力）

**核心方案**：打破 TS/JS 限制，支持主流语言编码辅助
**详细设计**：

- 插件名：`@ruobai/language-adapter`
- 实现逻辑：定义代码解析、运行、调试、依赖管理通用接口；内置 Python、Go、Java、Rust 适配器；支持自定义语言适配器插件扩展
- 架构兼容：独立适配层，向上提供统一接口，向下对接各语言工具链

#### 4. 全链路可观测性看板（工业可靠性能力）

**核心方案**：全局运行数据统计，支撑问题定位与性能优化
**详细设计**：

- 插件名：`@ruobai/observability`
- 实现逻辑：统计任务成功率、错误分布、Token 消耗、模型耗时、沙箱拦截率；提供全局大盘 + 单任务详情看板，支持多维度筛选；支持自定义异常告警
- 架构兼容：基于事件日志聚合统计，不侵入业务逻辑

#### 5. 代码内容安全合规校验（企业合规能力）

**核心方案**：规避敏感信息泄露、开源协议风险，满足企业合规要求
**详细设计**：

- 插件名：`@ruobai/code-compliance`
- 实现逻辑：检测敏感信息、开源许可证、企业编码规范三类风险；风险自动拦截写入，高风险触发人工审批；自动生成合规报告，支持自定义规则库
- 架构兼容：代码写入前置校验中间件，不侵入生成逻辑

#### 6. 细粒度权限与审计体系（企业合规能力）

**核心方案**：企业级权限管控与全量操作审计，满足合规要求
**详细设计**：

- 插件名：`@ruobai/rbac-audit`
- 实现逻辑：支持管理员、开发者、访客等角色，细粒度管控工具、文件、配置权限；全量操作日志留存，多维度筛选审计；自动生成周期合规报告
- 架构兼容：扩展用户体系与事件日志，不修改核心执行逻辑

#### 7. 全离线私有化部署方案（企业合规能力）

**核心方案**：纯内网离线运行，满足高安全等级项目需求
**详细设计**：

- 交付物：离线部署包 + Docker Compose 一键部署方案
- 核心能力：本地大模型、本地向量检索、本地代码索引全链路本地化，无外网依赖；配套运维监控面板，支持状态监控、日志排查
- 架构兼容：所有外部依赖均可替换为本地方案，核心架构无需改动
